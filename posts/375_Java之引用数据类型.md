# Java 引用数据类型

在Java中，数据类型分为两大类：**基本数据类型**和**引用数据类型（Reference Types）**。基本类型是存储“值”本身，而引用类型则存储的是指向对象的“内存地址”（即引用）。

打个比方：基本类型就像你口袋里直接装着的**现金**，而引用类型则像一张**银行卡**，卡本身不包含钱，但它存着能帮你找到你银行账户（堆内存中的对象）的“地址”。

### Java中的引用数据类型

Java中，所有的**类、接口、数组、枚举、注解**都属于引用数据类型。具体分为以下四类：

1. **类（Class）**：最普遍的引用类型，包括 `String`、`Integer` 等包装类，以及我们自定义的所有类。
2. **接口（Interface）**：定义一组行为规范，如 `List`、`Comparable`。
3. **数组（Array）**：存储同一类型元素的容器对象，如 `int[]`、`String[]`。
4. **枚举（Enum）**：定义一组常量集合，如 `enum Color {RED, GREEN, BLUE}`。

此外，还有一个特殊的字面量 **null**，它不指向任何对象，是所有引用类型的默认值。

------

### 引用类型 vs 基本类型

为了更清晰，我将它们进行对比：

| 对比维度     | **引用数据类型**                                   | **基本数据类型**                                      |
| :----------- | :------------------------------------------------- | :---------------------------------------------------- |
| **存储内容** | 存储对象在**堆内存**中的地址（引用）               | 直接存储**数值本身**                                  |
| **内存位置** | 变量本身在**栈**，对象实体在**堆**                 | 变量名和值都存储在**栈**中                            |
| **默认值**   | `null`（没有指向任何对象）                         | 有具体默认值（如 `int` 为 `0`，`boolean` 为 `false`） |
| **占用空间** | 引用大小固定（如32位JVM占4字节），但对象大小不固定 | 大小固定（由类型决定）                                |
| **生命周期** | 由JVM的垃圾回收器（GC）自动管理                    | 方法执行结束即被销毁                                  |
| **操作方式** | 通过引用操作对象的行为（方法）                     | 直接操作数值                                          |

------

### 一个关键理解：`String` 的特殊性

`String` 虽然也是引用类型，但它有一个特殊之处——**不可变性（Immutable）**。当你修改一个 `String` 变量时，JVM并不是在原有对象上修改，而是在堆中创建一个新的 `String` 对象，然后让引用指向新对象。这与其他引用类型（如 `StringBuilder`）的行为不同。

------

### 值传递与引用传递

这是理解引用类型最易出错的地方。你需要记住：**Java中只有“值传递”**。

- **对于基本类型**：传递的是**值的副本**。方法内修改参数，不影响外部变量。
- **对于引用类型**：传递的是**引用的副本**（即地址值的拷贝）。这意味着，方法内通过引用修改了对象的属性，会影响到外部对象；但如果在方法内将引用指向一个新对象，外部引用不受影响。

**代码示例：**

```java
public class Test {
    public static void main(String[] args) {
        int num = 10;
        changeNum(num);
        System.out.println(num); // 输出 10（基本类型不受影响）

        Person p = new Person("张三");
        changeName(p);
        System.out.println(p.name); // 输出 "李四"（对象属性被修改）

        changePerson(p);
        System.out.println(p.name); // 输出 "李四"（引用指向新对象不影响外部）
    }

    static void changeNum(int x) { x = 20; }

    static void changeName(Person p) { p.name = "李四"; }

    static void changePerson(Person p) { p = new Person("王五"); }
}
```

------

### 注意事项

1. **== 与 equals() 的区别**：
   - 对引用类型使用 `==`，比较的是**内存地址**（是否指向同一个对象）。
   - 要比较对象**内容**是否相同，应使用 `equals()` 方法（如 `String` 类已重写该方法）。
2. **垃圾回收**：当没有任何引用指向一个对象时，该对象就会成为垃圾，被JVM的垃圾回收器自动清理。
