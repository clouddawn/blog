# Java 变量

在Java中，**变量**可以理解为一块命名的内存空间，用来存储程序运行时可以改变的数据。

它的基本声明格式是：`数据类型 变量名 = 初始值;`

------

### 1. 变量的三大分类（按作用域划分）

根据变量声明的位置和生命周期，Java将变量分为三类：

| 类型                                         | 声明位置                            | 存储位置                     | 默认值                            | 生命周期                           | 典型场景                                                     |
| :------------------------------------------- | :---------------------------------- | :--------------------------- | :-------------------------------- | :--------------------------------- | :----------------------------------------------------------- |
| **局部变量** （Local Variable）              | 方法、构造器或代码块 `{...}` 内部   | **栈内存**                   | **无默认值**， **必须手动初始化** | 方法执行时创建，执行结束立即销毁   | 方法内的临时计算结果、循环计数器（如 `int i = 0`）。         |
| **成员变量** （实例变量，Instance Variable） | 类内部，方法外部（**无** `static`） | **堆内存** （跟随对象）      | 有默认值 （如 `int` 为 `0`）      | 对象创建时诞生，对象被GC回收时消亡 | 描述对象固有属性（如一个学生对象的 `name` 和 `age`）。       |
| **静态变量** （类变量，Static Variable）     | 类内部，方法外部（**有** `static`） | **方法区/元空间** （跟随类） | 有默认值                          | 类加载时诞生，类卸载时消亡         | 所有对象共享的数据（如全局配置、计数器 `static int count`）。 |

------

### 2. 命名规范

遵循Java的命名规范能让代码更易读：

1. **首字母小写**：采用**驼峰命名法**，如 `studentName`、`userAge`（类名才是首字母大写）。
2. **见名知意**：避免用 `a`、`b`，尽量用有意义的英文单词，如 `totalPrice`。
3. **允许字符**：只能以字母、下划线 `_`、美元符 `$` 开头（数字不能开头），且不能使用Java关键字（如 `class`、`int`、`public`）。

------

### 3. 初始化规则

- **局部变量（必须手动初始化）**：如果你在方法里写 `int num;` 然后直接 `System.out.println(num);`，**编译器会直接报错**。因为它没有默认值，必须显式赋值，比如 `int num = 10;`。
- **成员变量和静态变量（有默认值）**：如果你不手动赋值，JVM会给一个默认的“零值”。例如 `int` 是 `0`，`boolean` 是 `false`，**引用类型**是 `null`。

------

### 4. 变量的“变”与“不变”（`final` 关键字）

虽然叫“变量”，但如果你在声明时加上 `final` 关键字，它就会变成**常量**（值不可变）：

```java
final double PI = 3.14159; // PI 一旦赋值，后续无法修改
```

如果是引用类型被 `final` 修饰，代表**引用地址不可变**（不能指向新对象），但对象内部属性仍可修改。

------

### 代码全景演示

```java
public class VariableExample {
    static int staticVar = 100; // 静态变量（类变量），所有对象共享
    int instanceVar = 50;       // 成员变量（实例变量），每个对象独立

    public void testMethod() {
        int localVar = 10;      // 局部变量，必须手动初始化
        System.out.println("局部变量：" + localVar);
        System.out.println("成员变量：" + instanceVar);
        System.out.println("静态变量：" + staticVar);
    }

    public static void main(String[] args) {
        // 静态变量可以直接通过类名访问（推荐）
        System.out.println(VariableExample.staticVar); 
        
        // 成员变量必须通过对象访问
        VariableExample obj = new VariableExample();
        System.out.println(obj.instanceVar); 
        
        obj.testMethod();
    }
}
```

------

### 总结记忆口诀

- **局部变量**：活在方法里，用完就没了，**必须给初值**。
- **成员变量**：活在对象里，每个对象一份，**有默认值**。
- **静态变量**：活在类里，所有对象共用一份，**有默认值**。
