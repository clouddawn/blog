# Java 基本数据类型之间的转换

在Java中，**基本数据类型之间的转换**分为两大类：**自动类型转换（隐式转换）**和**强制类型转换（显式转换）**。理解它们的关键在于**数据范围（精度）**和**内存大小**。

Java是强类型语言，但对于基本数值类型（`byte`、`short`、`char`、`int`、`long`、`float`、`double`），在满足特定规则时，编译器会允许自动转换，否则必须手动强制转换。

------

### 1. 自动类型转换（隐式转换）

**规则**：当把一个**取值范围小**或**精度低**的类型赋值给**取值范围大**或**精度高**的类型时，Java会自动完成转换，无需任何语法标记。

**转换方向（从低到高）**：

```
byte → short → int → long → float → double
     ↘ char  ↗
```

（`char` 可以自动转为 `int` 及以上类型，但 `char` 与 `byte`、`short` 之间不能自动转换，因为 `char` 是无符号的，取值范围不同。）

```java
int intNum = 100;
long longNum = intNum;        // int 自动转为 long
float floatNum = longNum;      // long 自动转为 float（可能有精度损失，但语法允许）
double doubleNum = floatNum;   // float 自动转为 double

char c = 'A';
int code = c;                 // char 自动转为 int（得到ASCII/Unicode码值65）
```

**特殊说明**：

- `byte`、`short`、`char` 在参与算术运算（如 `+`、`-`）时，会被**自动提升为 int**，结果也是 `int`，除非显式强制转换。

```java
byte a = 10;
byte b = 20;
byte c = a + b; // 编译错误！因为 a+b 结果是 int，需要强制转换
int d = a + b;  // 正确，结果自动为 int
```

------

### 2. 强制类型转换（显式转换）

**规则**：当把**取值范围大**或**精度高**的类型赋值给**取值范围小**或**精度低**的类型时，必须手动进行强制转换，语法是在值前加 `(目标类型)`。

**格式**：`目标类型 变量名 = (目标类型) 源变量;`

```java
long longNum = 100L;
int intNum = (int) longNum;      // 强制转为 int

double pi = 3.1415926;
float f = (float) pi;            // 强制转为 float（可能丢失小数位）

int big = 300;
byte small = (byte) big;         // 强制转为 byte，结果会溢出（300 的 byte 值是 44，因为截断）
```

### 3. 转换中的常见问题

#### （1）精度丢失（浮点数转整数）

将浮点类型（`float`/`double`）转为整数类型时，**直接截断小数部分**（不是四舍五入）。

```java
double d = 9.99;
int i = (int) d;  // i 的值为 9，小数部分被丢弃
```

#### （2）数据溢出（大范围转小范围）

当转换的值超出目标类型的取值范围时，会**发生截断**，得到的结果是余数（取模），不符合直觉。

```java
int num = 128;
byte b = (byte) num;  // byte 最大值127，128 转为 byte 得到 -128（因为溢出）
```

#### （3）`char` 与整数之间的特殊转换

`char` 是无符号整数（0~65535），可以赋给 `int`、`long` 等，但若将大整数赋给 `char`，需要强制转换，且超出范围会溢出。

```
char ch = 65;          // 合法，自动转为 'A'
int code = ch;         // 自动转为 65
char invalid = 70000;  // 编译错误，超出范围，需要强制转换但结果可能乱码
```

#### （4）布尔类型不能参与转换

`boolean` 类型不参与任何数值转换，既不能自动转换，也不能强制转换（编译直接报错）。

```java
boolean flag = true;
int i = (int) flag;   // 编译错误！
```

### 类型转换总结表

| 转换方向                                             | 是否自动   | 风险                   |
| :--------------------------------------------------- | :--------- | :--------------------- |
| 低精度 → 高精度（如 int→long）                       | ✅ 自动     | 无风险，安全           |
| 高精度 → 低精度（如 long→int）                       | ❌ 必须强制 | **可能溢出或精度丢失** |
| char ↔ int（char→int自动，int→char强制）             | 单向自动   | int→char可能溢出       |
| float ↔ double（float→double自动，double→float强制） | 单向自动   | double→float精度丢失   |
| 布尔类型与任何数值类型                               | ❌ 完全禁止 | 不适用                 |

### 最佳实践

- **在强制转换前，尽量先检查值是否在目标范围内**（比如用 `if` 判断），避免意外溢出。
- **浮点数转整数**时，如果希望四舍五入，可以使用 `Math.round()` 方法。
- 在混合运算中，注意**整型提升**规则，避免意外溢出（例如 `int` 相乘可能溢出，可先转 `long`）。
- 当需要精确计算（如金融货币）时，**不要使用浮点数转换**，应使用 `BigDecimal`。
