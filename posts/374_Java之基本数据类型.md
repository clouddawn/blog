# Java 基本数据类型

在Java中，**基本数据类型（Primitive Types）** 是语言最基础的构成单元，它们不是对象，直接存储在**栈内存**中，因此存取效率极高。Java是强类型语言，使用任何变量前都必须声明其类型。

Java一共定义了**8种**基本数据类型，按用途可以分为四大类：

### 1. 整数类型（4种）

用于存储整数值，不包含小数部分。它们的主要区别在于**占用的内存空间**和**取值范围**。

| 类型      | 占用空间      | 取值范围（约数）          | 默认值 | 适用场景                                                     |
| :-------- | :------------ | :------------------------ | :----- | :----------------------------------------------------------- |
| **byte**  | 1字节（8位）  | -128 ~ 127                | 0      | 节省内存，主要用于处理文件流或网络传输的原始字节。           |
| **short** | 2字节（16位） | -32,768 ~ 32,767          | 0      | 较少使用，通常用于节省内存的大数组，或与特定底层系统交互。   |
| **int**   | 4字节（32位） | -2^31 ~ 2^31-1 （约21亿） | 0      | **最常用的整数类型**。默认情况下，代码中的整数常量（如 `100`）就是 `int` 类型。 |
| **long**  | 8字节（64位） | -2^63 ~ 2^63-1            | 0L     | 用于超出 `int` 范围的数值（如时间戳、文件大小）。**注意**：赋值时数值后需加 `L` 或 `l`（如 `long time = 10000000000L;`）。 |

------

### 2. 浮点类型（2种）

用于存储带小数点的数值（即实数）。由于计算机二进制无法精确表示所有小数，浮点数运算存在微小误差。

| 类型       | 占用空间      | 精度                 | 默认值 | 适用场景                                                     |
| :--------- | :------------ | :------------------- | :----- | :----------------------------------------------------------- |
| **float**  | 4字节（32位） | 约7位有效十进制小数  | 0.0f   | 节省内存，适合处理音频、图像等大规模浮点数组。**注意**：赋值时数值后需加 `F` 或 `f`（如 `float price = 9.99f;`）。 |
| **double** | 8字节（64位） | 约16位有效十进制小数 | 0.0d   | **默认的浮点类型**（小数常量如 `3.14` 默认是 `double`）。科学计算、大多数商业应用首选。 |

> **特别注意**：如果需要绝对精确的小数计算（如金融货币），**不要使用 float 或 double**，应使用 `BigDecimal` 类。

------

### 3. 字符类型（1种）

**char** 用于表示单个字符。

- **占用空间**：2字节（16位，无符号）。
- **取值范围**：0 ~ 65,535（基于Unicode编码，可以表示中文）。
- **赋值方式**：使用**单引号**括起来。
  - 字母：`char letter = 'A';`
  - 中文：`char chinese = '中';`
  - 转义字符：`char newline = '\n';`（换行）
  - Unicode值：`char unicode = '\u4e2d';`（也代表'中'）

------

### 4. 布尔类型（1种）

**boolean** 只有两种值，用于逻辑判断。

- **取值**：`true`（真）或 `false`（假）。
- **占用空间**：Java规范没有明确定义大小，通常JVM实现时会按1字节或4字节处理。
- **默认值**：`false`。
- **用途**：条件判断（如 `if`、`while` 循环）。
